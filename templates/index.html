1. Encrypt and Upload

Select a file. The application will split it into blocks, encrypt the blocks, and upload the encrypted data to AWS S3.

2. Download and Decrypt

Enter the encrypted folder identifier displayed after uploading. The application will download the encrypted blocks, reconstruct the file, and verify its integrity.

How It Works

1. The selected file is divided into smaller blocks.
2. Each block is encrypted using AES-256-GCM.
3. Encrypted blocks and the manifest are uploaded to AWS S3.
4. The blocks can later be downloaded and decrypted.
5. SHA-256 hashes are compared to verify file integrity.
